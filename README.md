# Noah Mitchell — Personal research site

A lightweight, static personal site designed for GitHub Pages. There is no build
step and no framework dependency.

## Preview locally

Open `index.html` directly, or serve the directory with any static file server.

## Publish with GitHub Pages

Push the repository to GitHub, then enable Pages under **Settings → Pages** and
publish from the repository's root directory on the default branch.

## Content

- `index.html` contains all site copy and links.
- `styles.css` contains the responsive visual design.

## Profile photo

The profile photo is stored as `profile.jpg` and displayed in a square crop. Replace
that file with another square image to update it without changing the HTML.
